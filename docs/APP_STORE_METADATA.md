## Description

Catch Up turns staying informed into a small daily habit.

Set a morning alarm, choose the subjects you care about, and wake up to a concise briefing with a clear finish. Read a handful of neutral, cited summaries, understand why each development matters, and move on with your day.

Features:

- A real morning alarm built for your daily briefing
- World, energy, technology, business, and science topics
- Three to seven stories per session—never an infinite feed
- Direct links to original reporting
- Daily and longest reading streaks
- Offline access to the latest downloaded briefing
- Optional Screen Time shields for distracting apps
- Local reading history and preferences
- No ads or cross-app tracking

Catch Up cannot remove iPhone's system Stop control. Tap Start Catch-up on the alarm to open the briefing. Screen Time restrictions are optional and can be revoked in Settings.

## Review notes

Catch Up uses AlarmKit to schedule user-created alarms. The custom Start Catch-up secondary action opens the app; the system Stop action remains available.

Family Controls individual authorization is optional. If authorized, the user explicitly selects apps or categories in Apple's FamilyActivityPicker. A DeviceActivityMonitor extension applies Managed Settings shields during the configured morning window. Completing the briefing clears the settings. The user can disable this feature or revoke Screen Time access at any time.

The app opens in demo mode with bundled sample stories, so review does not require backend credentials. To test live mode, provide a temporary review backend URL and access token in the App Review information—not in this public metadata.
