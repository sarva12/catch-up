# App icon source

The final App Store asset is `CatchUp/Resources/Assets.xcassets/AppIcon.appiconset/CatchUp-AppIcon-1024.png`.

It was generated with the built-in image-generation tool using this production prompt:

> Create a striking minimal 1024×1024 iOS app icon for a morning news habit app. Use a single bold geometric mark combining a rising sun at the top edge of an open newspaper. Flat vector-like Swiss editorial design, centered and recognizable at tiny sizes, pure black and warm white only. No words, letters, numbers, gradients, shadows, fine lines, device frame, transparency, rounded-corner mask, or watermark.

`CatchUp-AppIcon-source.png` retains the original generated raster. The asset-catalog version is a high-quality 1024×1024 downsample for Apple's icon slot.
